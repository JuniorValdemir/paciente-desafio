# Paciente Desafio

Sistema web simples para gerenciamento e cadastro de pacientes.

##  Tecnologias

* Java 8
* JSF 1.2 + Facelets
* PostgreSQL
* Maven (Tomcat 9)

## Como Executar

1. Precisa ser configurado o banco de dados criando o arquivo `src/main/resources/database.properties` com base no `database.properties.example`.
2. Execute o comando no terminal: mvn clean package cargo:run
